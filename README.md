# House Prices Prediction (Advanced Regression)

Проект по прогнозированию стоимости жилой недвижимости на основе физических характеристик, качества постройки и местоположения дома.

## Задачи проекта
- Провести комплексный Exploratory Data Analysis (EDA) и выявить ключевые факторы, влияющие на стоимость жилья.
- Построить автоматизированный конвейер предобработки данных с защитой от утечки данных.
- Обучить линейные модель с регуляризацией.
- Проанализировать остатки ошибки.

## Технологический стек
Python (pandas, numpy)
Scikit-learn (Pipeline, ColumnTransformer, GridSearchCV, Ridge, StandardScaler, OneHotEncoder)
Matplotlib / Seaborn** (визуализация)
Scipy (статистический анализ)

## Основные этапы и результаты

### 1. Предобработка данных 
Для чистой обработки данных без утечки был собран `ColumnTransformer`:
- Числовые признаки: заполнение пропусков медианой `StandardScaler`.
- Категориальные признаки: заполнение модой `OneHotEncoder()`.

### 2. Метрики качества модели (Ridge Regression)
Подбор гиперпараметра регуляризации alpha производился через `GridSearchCV` с 5-фолдовой кросс-валидацией.

R² Score =  0.842 
RMSE* = $28,400** 
MAE* = $18,200** 

Выводы
1. Наибольший положительный вклад в цену вносят общая жилая площадь (`GrLivArea`), качество внутренней отделки (`OverallQual`) и вместимость гаража (`GarageCars`).
2. Район расположения (`Neighborhood`) оказывает сильное влияние: престижные районы добавляют к стоимости существенную премиальную наценку.


## Как запустить проект 

1. Клонировать репозиторий:
   git clone [https://github.com/Hudenchik/House-Prices-Prediction]
   cd house-prices-regression
2. Установить зависимости:
pip install -r requirements.txt

3. Скачать датасет House Prices на Kaggle и положить файл train.csv в папку data/.

4. Запустить обучение через скрипт:
python src/train_pipeline.py
